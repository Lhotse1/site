# Portfolio website

Personal portfolio site for Arry Weller (finance professional). Showcases data/finance projects (Excel dashboards, analyses) with downloadable files.

## Tech and hosting
- Plain static site: HTML, CSS, a little JavaScript. No frameworks or build step unless I ask.
- Hosted on GitHub Pages from the `main` branch of a PUBLIC repo (github.com/Lhotse1/site). Every push to `main` goes live.
- Previewed locally with VS Code's Live Server extension.

## How to work with me
- I'm learning web development and Git. Briefly explain what you're changing and why, and explain any Git command before you run it.
- For anything bigger than a small fix, propose a plan before editing files.
- Never run `git push`, `git push --force`, `git reset --hard` or delete files without asking me first.
- Suggest a clear commit message after each logical change.

## Rules for the site
- File and folder names: lowercase, hyphens instead of spaces (GitHub Pages is case-sensitive).
- Use relative links and paths (e.g. `images/photo.png`), never absolute paths from my computer.
- Every page must work on mobile and desktop.
- Every image needs meaningful `alt` text. Keep images compressed for the web.
- Every page needs its own `<title>` and meta description.
- Keep styling in `css/style.css` and reuse existing classes before adding new ones.

## Privacy
- The repo is public. Never add personal contact details beyond what I approve, confidential employer/client data, passwords or API keys.
- Flag any file over 25 MB before it's committed.
